# @tsumi/shared

Shared TypeScript types, constants, and utilities for the Tsumi platform.

## Usage

### In Next.js Frontend
```typescript
import { User, Errand, TRUST_BADGES } from "@tsumi/shared";
```

### In Node.js Backend
```typescript
import { JWTPayload, ERRAND_STATUS } from "@tsumi/shared";
```

## Building
```bash
npm run build
```
